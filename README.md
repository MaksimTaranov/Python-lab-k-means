# Python-lab-k-means

Лабораторная работа №1 по Python. Реализация метода k-средних на чистом Python.
Программа генерирует двумерные данные, разбивает их на кластеры и строит графики.

## Возможности

- Обучение модели и определение кластера для новых точек.
- Расчёт inertia — суммы квадратов расстояний от точек до центров своих кластеров.
- Вывод количества точек в каждом кластере.
- Визуализация кластеров и их центров.
- Метод локтя для выбора количества кластеров по графику inertia.

## Установка

Требуются Python 3.13 или новее и uv.

```bash
git clone https://github.com/MaksimTaranov/python-lab-k-means.git
cd python-lab-k-means
uv sync
```

Команды запуска и проверок выполняются из корня репозитория, где находится `pyproject.toml`.

## Запуск

Кластеризация с настройками по умолчанию:

```bash
uv run python -m lab_01.cli
```

Запуск с указанием параметров:

```bash
uv run python -m lab_01.cli --samples 300 --k 3 --iter 100 --seed 42
```

Программа выводит размеры кластеров и inertia, затем показывает график.

Метод локтя:

```bash
uv run python -m lab_01.cli --samples 300 --elbow --max-k 8 --seed 42
```

На графике нужно выбрать значение k, после которого inertia уменьшается заметно медленнее.

| Аргумент | Назначение | По умолчанию |
| --- | --- | --- |
| `--samples` | Общее количество точек | `300` |
| `--k` | Количество кластеров в обычном режиме | `3` |
| `--iter` | Максимальное количество итераций обучения | `100` |
| `--seed` | Начальное значение генератора случайных чисел | `42` |
| `--elbow` | Включить метод локтя | Выключен |
| `--max-k` | Максимальное k для метода локтя | `8` |

По умолчанию данные создаются вокруг трёх случайных центров.
Аргумент `--k` задаёт количество кластеров для модели, а не количество облаков при генерации.
Результат обучения зависит от начальных центров; одинаковый seed обеспечивает воспроизводимость.

Справка по аргументам:

```bash
uv run python -m lab_01.cli --help
```

## Тесты

```bash
uv run python -m pytest
```

Тесты проверяют расстояния, разделение трёх известных групп, воспроизводимость,
невозрастание inertia при увеличении числа итераций, разные значения k и предсказания.
